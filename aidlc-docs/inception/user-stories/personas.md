# User Personas

## Event Organizer
**Role**: Creates and manages community events
**Primary Goals**: 
- Create engaging community events
- Manage event logistics efficiently
- Track event success and attendance

**Key Responsibilities**:
- Event creation and setup
- Budget management
- Task assignment to coordinators
- Event promotion and sharing

## Event Coordinator  
**Role**: Assists organizers with event planning tasks
**Primary Goals**:
- Complete assigned tasks on time
- Support event execution
- Collaborate with organizers effectively

**Key Responsibilities**:
- Task execution and status updates
- Event preparation activities
- Communication with organizers

## Event Attendee
**Role**: Participates in community events
**Primary Goals**:
- Discover interesting community events
- Easily RSVP to events
- Stay informed about event details

**Key Responsibilities**:
- Event discovery and registration
- RSVP management
- Event participation
