# AI-DLC Demo App Prompts

Sample prompts to demonstrate AI-DLC methodology for greenfield CRUD applications with excellent visual design.

## 1. Personal Library Manager

### Prompt:
```
Using AI-DLC, I want to create a personal library management system where users can add books, track reading progress, write reviews, and get reading recommendations. The app should have a beautiful book grid layout, reading statistics dashboard, and the ability to categorize books by genre, author, and reading status.
```

### Rationale:
- **Visual Appeal**: Book covers create naturally attractive grid layouts
- **CRUD Complexity**: Books, reviews, categories, reading progress - multiple related entities
- **Dashboard Potential**: Reading stats, progress charts, recommendation algorithms
- **Familiar Domain**: Everyone understands books, focuses attention on AI-DLC process

## Why These Prompts Work for AI-DLC Demos

### Common Strengths:
- **Visual Appeal**: Each app has natural opportunities for attractive UI
- **CRUD Complexity**: Multiple entities with relationships
- **Dashboard Potential**: Charts, analytics, and data visualization
- **Real-world Utility**: Practical applications people actually want
- **Familiar Domains**: Easy to understand, focus stays on AI-DLC process

### AI-DLC Showcase Opportunities:
- **Inception Phase**: Requirements analysis, user stories, application design
- **Construction Phase**: Technical architecture, database design, API planning
- **Documentation**: Comprehensive docs generated in `aidlc-docs/` folder
- **Quality Control**: Structured approach vs. random prompting
