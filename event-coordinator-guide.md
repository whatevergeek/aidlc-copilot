# Event Coordinator Guide

## Welcome, Event Coordinator!

As an **Event Coordinator**, you're the reliable support that makes events successful. This guide helps you complete assigned tasks efficiently, support event execution, and collaborate effectively with organizers.

## Your Goals
- ✅ Complete assigned tasks on time
- ✅ Create tasks for events that need support
- ✅ Support smooth event execution
- ✅ Collaborate effectively with organizers and other coordinators
- ✅ Contribute to community event success
- ✅ Browse and RSVP to events as an attendee

## Getting Started

### Account Setup
```
1. Register with your email and select "Event Coordinator" role
2. Login to access the platform
3. Browse events and create tasks for any event
4. Check your task dashboard regularly
```

### Understanding Your Role
- **Task Creator & Executor**: Create and complete task assignments
- **Event Support**: Help with any event in the community
- **Team Player**: Support organizers and other coordinators
- **Problem Solver**: Handle issues as they arise
- **Communicator**: Keep everyone updated on progress

## Task Management Dashboard

### Your Task View
- **Assigned Tasks**: Tasks specifically given to you
- **Task Status**: Pending, In Progress, Completed
- **Due Dates**: When tasks need to be finished
- **Task Details**: Full descriptions and requirements

### Task Workflow
```
1. Browse Events to find ones needing support
2. Create Tasks for events (or receive assignments)
3. Review Task Details (description, due date, requirements)
4. Update Status to "In Progress"
5. Complete the Task
6. Mark as "Completed"
7. Communicate with event organizers (if needed)
```

## Working with Tasks

### Task Types You Might Receive

**Pre-Event Tasks:**
- Venue scouting and booking
- Vendor research and coordination
- Supply shopping and preparation
- Marketing material creation
- Registration system setup

**Event Day Tasks:**
- Early setup and preparation
- Registration/check-in management
- Equipment operation
- Guest assistance and guidance
- Real-time problem solving

**Post-Event Tasks:**
- Cleanup and breakdown
- Equipment return
- Thank you message sending
- Feedback collection
- Final reporting

### Task Management Best Practices

#### When You Receive a Task
1. **Read Carefully**: Understand all requirements
2. **Ask Questions**: Clarify anything unclear immediately
3. **Estimate Time**: Plan when you'll complete it
4. **Update Status**: Mark as "In Progress" when you start
5. **Communicate**: Keep organizer informed of progress

#### During Task Execution
- **Stay Focused**: Complete one task at a time
- **Document Issues**: Note any problems encountered
- **Seek Help**: Ask organizer if you get stuck
- **Update Progress**: Keep status current
- **Quality Check**: Ensure task meets requirements

#### Task Completion
- **Final Review**: Double-check all requirements met
- **Mark Complete**: Update status in system
- **Report Back**: Inform organizer of completion
- **Share Learnings**: Note what worked well or could improve

## Communication with Organizers

### Effective Collaboration
- **Proactive Updates**: Don't wait to be asked about progress
- **Clear Communication**: Be specific about status and issues
- **Solution-Oriented**: Suggest solutions when reporting problems
- **Timely Responses**: Reply to messages promptly
- **Professional Tone**: Maintain positive, helpful attitude

### When to Contact the Organizer
- **Task Clarification**: When requirements are unclear
- **Resource Needs**: When you need additional materials or access
- **Timeline Issues**: When you can't meet the deadline
- **Problem Solving**: When you encounter obstacles
- **Completion Updates**: When tasks are finished

## Event Day Coordination

### Pre-Event Preparation
- **Arrive Early**: Get to venue with time to spare
- **Check Equipment**: Ensure everything is working
- **Review Tasks**: Confirm your responsibilities
- **Coordinate with Team**: Connect with other coordinators
- **Be Ready**: Prepared for last-minute changes

### During the Event
- **Stay Alert**: Monitor for issues or needs
- **Be Helpful**: Assist attendees and other team members
- **Follow Through**: Complete all assigned tasks
- **Communicate**: Keep organizer informed of any issues
- **Stay Flexible**: Adapt to changing needs

### Post-Event Activities
- **Complete Cleanup**: Finish all breakdown tasks
- **Return Items**: Ensure borrowed/rented items are returned
- **Final Updates**: Mark all tasks as completed
- **Provide Feedback**: Share observations with organizer
- **Celebrate Success**: Acknowledge the team's achievements

## Common Coordinator Scenarios

### Scenario 1: Venue Setup Coordination
```
Task: "Set up registration table and welcome area"
Actions:
1. Arrive 1 hour before event
2. Locate designated setup area
3. Arrange tables, chairs, signage
4. Test any equipment (laptops, printers)
5. Prepare welcome materials
6. Update organizer when complete
```

### Scenario 2: Supply Management
```
Task: "Purchase and organize catering supplies"
Actions:
1. Review supply list and budget
2. Research best vendors/stores
3. Purchase items within budget
4. Organize supplies for easy access
5. Keep receipts for organizer
6. Report completion with expense summary
```

### Scenario 3: Guest Assistance
```
Task: "Manage event check-in and guest questions"
Actions:
1. Set up check-in area early
2. Review guest list and event details
3. Greet attendees warmly
4. Answer questions or direct to organizer
5. Handle any issues professionally
6. Keep organizer informed of attendance
```

## Troubleshooting Common Issues

### Task Confusion
- **Read task description completely**
- **Ask organizer for clarification immediately**
- **Confirm understanding before starting**
- **Document any assumptions made**

### Time Management Problems
- **Break large tasks into smaller steps**
- **Start tasks early when possible**
- **Communicate timeline concerns immediately**
- **Ask for help if falling behind**

### Resource or Access Issues
- **Identify what you need specifically**
- **Contact organizer with clear request**
- **Suggest alternative solutions**
- **Keep trying while waiting for response**

### Communication Breakdowns
- **Use multiple communication channels if needed**
- **Be clear and specific in messages**
- **Follow up if you don't get responses**
- **Escalate to organizer if critical**
